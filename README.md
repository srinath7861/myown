# DreamHome - Real Estate Website Hero Section

A modern, responsive real estate website with a stunning hero section featuring advanced search functionality, beautiful animations, and a clean design.

## Features

### Hero Section
- **Eye-catching Design**: Gradient backgrounds with floating animated cards
- **Advanced Search**: Multi-tab search with filters for property type, price range, and bedrooms
- **Responsive Layout**: Fully responsive design that works on all devices
- **Smooth Animations**: Entrance animations, hover effects, and parallax scrolling
- **Statistics Display**: Animated counters showing key metrics

### Navigation
- **Sticky Header**: Fixed navigation with blur effect
- **Mobile Menu**: Hamburger menu for mobile devices
- **Smooth Transitions**: Hover effects and active states

### Search Functionality
- **Three Search Modes**: Buy, Rent, and Sell tabs
- **Smart Filters**: Property type, price range, and bedroom filters
- **Input Validation**: Form validation with visual feedback
- **Keyboard Support**: Enter key to search, tab navigation

### Featured Properties
- **Property Cards**: Interactive cards with hover effects
- **Property Details**: Price, location, beds, baths, and square footage
- **Status Badges**: Featured, New, and Hot Deal indicators

## Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: Modern styling with CSS Grid, Flexbox, and animations
- **JavaScript**: Vanilla JS for interactivity
- **Google Fonts**: Inter font family for clean typography

## How to Use

1. Simply open the `index.html` file in a web browser
2. No build process or dependencies required
3. All assets are self-contained or loaded from CDNs
