🤖 Adriana Chatbot - Test Page

✅ System Components

  • chatbot_widget.html - Main chatbot widget with full functionality
  • chatbot_backend.php - Backend API for data storage and retrieval
  • admin_dashboard.php - Admin panel to view conversations and users
  • chatbot_data.json - JSON file storing all user and conversation data

🚀 Features Implemented

  • ✅ User registration with name, email, and mobile number
  • ✅ Automatic user recognition on return visits
  • ✅ Complete conversation history storage in JSON format
  • ✅ Previous conversation display for returning users
  • ✅ Continue chatting from where user left off
  • ✅ Real-time message saving to backend
  • ✅ Admin dashboard with statistics and conversation viewer
  • ✅ Data export functionality
  • ✅ Automatic backup system (keeps last 10 backups)
  • ✅ Search functionality in admin panel

📋 How It Works

  1. First Visit: User provides name, email, and mobile number
  2. Data Storage: User info and all messages are saved to JSON file via PHP backend
  3. Return Visit: System recognizes user by email and name combination
  4. History Display: Previous conversations are loaded and displayed
  5. Continuation: User can continue chatting with full context
  6. Admin Access: View all users and conversations in the admin dashboard

⚙️ Configuration Required

// Line 1564 - Update backend URL if needed const BACKEND_URL = 'chatbot_backend.php'; // Line 1565 - Add your Gemini API key const GEMINI_API_KEY = 'YOUR_ACTUAL_API_KEY_HERE';

// Line 5 - Change the admin password $ADMIN_PASSWORD = 'admin123'; // Change this to a secure password!

🔒 Security Considerations

  • ⚠️ Change the default admin password immediately
  • ⚠️ Implement proper authentication for production use
  • ⚠️ Consider using a database instead of JSON for large-scale deployments
  • ⚠️ Add HTTPS for secure data transmission

  • ⚠️ Sanitize all user inputs properly

📊 Data Structure

The JSON file stores data in the following structure:

{ "users": [ { "id": "user_unique_id", "name": "John Doe", "email": "john@example.com", "mobile": "+1234567890", "created_at": "2024-01-15 10:30:00", "last_login": "2024-01-15 10:30:00", "login_count": 1 } ], "conversations": [ { "id": "conv_unique_id", "user_id": "user_unique_id", "date": "2024-01-15", "started_at": "2024-01-15 10:30:00", "messages": [ { "id": "msg_unique_id", "sender": "user|bot", "message": "Message content", "timestamp": "2024-01-15 10:30:00" } ] } ], "metadata": { "created_at": "2024-01-15 10:00:00", "last_updated": "2024-01-15 10:30:00", "version": "1.0" } }

🛠️ Troubleshooting

  • Chatbot not saving data: Check PHP is enabled and file permissions are correct
  • Admin panel not loading: Ensure chatbot_data.json exists and is readable
  • AI responses not working: Add your Gemini API key in the configuration
  • Widget not appearing: Check browser console for JavaScript errors
